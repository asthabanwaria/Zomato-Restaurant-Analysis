# 🍽️ Zomato Restaurant Analysis

An end-to-end Data Analytics project that analyzes the Zomato Bangalore Restaurant dataset using Python, SQL, and Power BI to uncover business insights and visualize restaurant trends.


📌 Project Overview

The objective of this project is to perform data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and interactive dashboard creation to understand restaurant distribution, customer preferences, pricing patterns, and ratings.

This project demonstrates the complete data analytics workflow from raw data to actionable business insights.

🎯 Objectives

- Clean and preprocess the raw dataset.
- Perform Exploratory Data Analysis (EDA).
- Solve business problems using SQL.
- Create an interactive Power BI dashboard.
- Generate meaningful business insights.


🛠️ Tech Stack

- Python
  - Pandas
  - NumPy
  - Matplotlib
  -SQL (MySQL)
- Power BI
- Git & GitHub

📂 Dataset

The dataset contains information about restaurants in Bangalore, including:

- Restaurant Name
- Location
- Restaurant Type
- Cuisine
- Online Ordering
- Table Booking
- Customer Rating
- Number of Votes
- Approximate Cost for Two
- Reviews


🧹 Data Cleaning

The following preprocessing steps were performed using Pandas:

- Removed duplicate records
- Handled missing values
- Converted ratings to numeric values
- Cleaned the approximate cost column
- Converted appropriate columns to correct data types
- Removed unwanted characters and formatting issues
- Exported the cleaned dataset for SQL and Power BI analysis

📊 Exploratory Data Analysis (EDA)

The following business questions were explored:

1. Which locations have the highest number of restaurants?
2. Which restaurant types are most common?
3. Which cuisines are the most popular?
4. Which locations have the highest average ratings?
5. How does restaurant cost vary across Bangalore?
6. How are restaurant ratings distributed?
7. Do online ordering and table booking affect restaurant ratings?
8. Which restaurants receive the highest customer votes?
9. Which areas have the highest restaurant density?
10. Which city categories contain the most restaurants?

📊 Key Insights

- BTM has the highest number of restaurants.
- Koramangala is one of the busiest food hubs.
- North Indian cuisine is the most popular.
- Casual Dining and Quick Bites dominate the market.
- Restaurants with higher ratings generally receive more customer votes.
- Online ordering is offered by a significant number of restaurants.
- Premium locations tend to have higher average restaurant ratings.
